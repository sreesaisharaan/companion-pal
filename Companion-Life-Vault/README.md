# Companion Life — Obsidian Product Vault

Planning vault for a cross-platform personal-life app: tasks, reminders, monthly money tracking, and an evolving creature companion.

## Use this vault

1. Open Obsidian and choose **Open folder as vault**.
2. Select the `Companion-Life-Vault` folder.
3. Start at [[00-Start/Home]]. Work through the linked notes in order.
4. Copy prompts from [[04-AI-Prompts/Prompt Library]] into an AI coding assistant, replacing the bracketed placeholders.

## Product stance

The recommended first implementation is **React Native + Expo + TypeScript + Supabase**. It gives one iOS/Android codebase, fast iteration, and a practical path to notifications. Flutter remains a sound alternative if you prefer Dart and highly custom animation work.

## What is inside

- `00-Start` — navigation and decisions to make
- `01-Product` — vision, scope, roadmap, success metrics
- `02-UX` — flows and design principles
- `03-Engineering` — architecture and Supabase plan
- `04-AI-Prompts` — phase-by-phase paste-ready prompts
- `05-Delivery` — testing and launch checklists

## Guiding rule

The companion should encourage, never shame. Money tracking is informational by default; it must not behave like financial advice.
