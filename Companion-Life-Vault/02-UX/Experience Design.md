# Experience Design

## Navigation

Bottom tabs: **Today**, **Plan**, **Money**, **Companion**, **Profile**. A persistent quick-add action opens task, reminder, or expense capture.

## Key flows

### Daily loop

Open Today → see next action and companion check-in → complete/postpone task → receive small celebration and XP → optionally review spending snapshot.

### Task capture

Natural, short form: title required; date/time, repeat, list, and reminder optional. Default to “Today” only when the user chooses it—do not silently assign deadlines.

### Money entry

Tap add expense → amount → category → date (today default) → save → show updated monthly category total. Use clear currency formatting and allow edit/delete.

## Companion principles

- Celebrate action, not perfection.
- Never reduce level or scold after missed tasks.
- Provide pause/quiet modes and reduce-motion support.
- Keep reward feedback under two seconds and skippable.

## Accessibility and trust

Support screen readers, dynamic text, colour-independent status, contrast, haptics toggle, timezone-aware language, transparent notification settings, and an easy data export/delete path.
